# Backend Libraries (`src/backend/libs`)

This directory contains the implementations of the fundamental data structure classes used by the Autolang Virtual Machine.

## Key Files

- **`array.cpp` / `array.hpp`**: Implementation of Autolang VM dynamic arrays.
- **`map.cpp` / `map.hpp`**: Implementation of Autolang VM associative hash maps.
- **`set.cpp` / `set.hpp`**: Implementation of Autolang VM unique value sets.
