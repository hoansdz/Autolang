# Backend Directory (`src/backend`)

This directory houses the backend execution engine for Autolang, which is responsible for executing Compiled Program bytecode.

## Subdirectories

- **[libs](file:///d:/code/AutoLangC/src/backend/libs)**: Implementations of built-in data structures (array, map, set) utilized inside the virtual machine.
- **[optimize](file:///d:/code/AutoLangC/src/backend/optimize)**: Contains VM optimization components.
- **[vm](file:///d:/code/AutoLangC/src/backend/vm)**: The core implementation of the Autolang Virtual Machine (AVM) and bytecode interpreter loops.
