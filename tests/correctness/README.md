# Correctness Tests (`tests/correctness`)

This directory contains tests aimed at verifying that the compiler and virtual machine behave correctly according to the language specification.

## Subdirectories

- **[basic](file:///d:/code/AutoLangC/tests/correctness/basic)**: Validates syntax, basic language constructs, control structures, scopes, and types.
- **[stdlib](file:///d:/code/AutoLangC/tests/correctness/stdlib)**: Verifies the behavior and correctness of standard library modules (e.g. JSON, Regex, File IO, HTTP, Math).
